# TrabalhoFinal_AED-II

Trabalho final realizado para a disciplina de AED-II. Professor Carlo Kleber, 2026.2]

## Objetivo

Este trabalho investiga a eficiência de diferentes estruturas de dados no armazenamento e busca de sequências genéticas do vírus SARS-CoV-2, agente causador da COVID-19. O material genético viral é composto por nucleotídeos (Adenina, Citosina, Guanina e Timina/Uracila), demandando algoritmos altamente otimizados para o rastreamento rápido de mutações, identificação de novas linhagens e alinhamento de sequências. O objetivo central deste trabalho é analisar e comparar o desempenho estrutural de Árvores Digitais m-árias (onde m = 4, representando as quatro bases nitrogenadas) com Árvores Digitais Binárias no processamento de genomas virais. A metodologia consiste na idealização de uma aplicação computacional em que fragmentos genômicos são indexados nas referidas estruturas. Concluir-se-á, a partir de futuras análises experimentais e teóricas, qual abordagem oferece a melhor relação de efetividade considerando a complexidade de tempo, complexidade de espaço, tempo prático de execução e facilidade de implementação no âmbito do sequenciamento de larga escala.
